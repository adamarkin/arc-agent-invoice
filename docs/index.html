Arc Agent Invoice

Non-custodial invoices and onchain receipts for AI agents and freelancers, paid in Arc's native USDC. Network: Arc mainnet (chain ID 5042).

Units & safety. On Arc, USDC is the native gas token. Amounts here are native value (18-decimal units; 1 USDC = 1018 wei-style units), not the 6-decimal ERC-20 view at 0x3600…0000. Type amounts as normal USDC decimals (e.g. 1.5). The contract forwards payment to the payee in the same transaction and holds no funds. This site never asks for private keys or seed phrases — only your wallet signs, and you review each transaction. Always verify the contract address on explorer.arc.io. Unaudited; use small amounts.
